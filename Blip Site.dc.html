If it can make an HTTPS request, it works — one POST with a bearer key. If it can't, the bridge pretends to be a receipt printer and does it for you.
who sees what
The token is the key: unguessable, and the file lives in a private bucket behind 5-minute signed links. Staff see their own store, nothing else.
if the wifi dies
The box queues and retries; the console marks it offline within a minute. Nothing is lost — the codes go out when the line comes back.
do you have to talk to us
No. Buy it from this page, read the docs, run the console yourself. Email if you want — a person answers — but nothing is locked behind a call.
