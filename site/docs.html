One endpoint. Ten minutes.

There is no SDK to install and nothing runs on the device side. You hold an API key, you name a box, you pass a URL. Everything after that is ours.

1 · Get your key

Create an API key in the console with the devices:trigger scope. It's shown once — store it like a password.

2 · Trigger a box
$ curl -X POST https://api.ditto.example/api/v1/devices/dev_8f21/trigger \ -H "Authorization: Bearer sk_live_…" \ -H "Idempotency-Key: 9f3a-…" \ -H "Content-Type: application/json" \ -d '{ "action": "show_qr", "payload": { "url": "https://yourshop.example/r/8f21" } }'
201 · commandId cmd_… · credit held → the box shows your QR → ack settles it
3 · That's the integration

The box shows the code and confirms it — that confirmation spends the credit. A request that can't be delivered in time expires instead of showing late, and the hold is released.

You host the content. Always.

The URL goes straight into the QR — we never fetch, render, or store what's behind it. Your customer data never leaves your systems.
